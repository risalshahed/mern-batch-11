# Todo CRUD App with React & Tailwind

### Clone the Repository

```bash
https://github.com/risalshahed/mern-batch-11.git
```

### Change to the Directory

```bash
cd mern-batch-11
```

### Switch to the Branch

```bash
git switch module-23-todo-react-tw
```

### Run the Project Locally

```bash
npm i
npm run dev
```
